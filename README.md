# 🗳 Decentralized Voting System (Solidity)

## 📌 Description
This project is a simple decentralized voting system built using Solidity and Remix IDE. It demonstrates core blockchain concepts like smart contracts, events, validations, and access control.

## ⚙️ Features
- Add candidates (only owner)
- Vote once per user
- View results
- Event logging
- Input validation using require()

## 🛠 Tech Stack
- Solidity
- Remix IDE
- Ethereum (Remix VM)
